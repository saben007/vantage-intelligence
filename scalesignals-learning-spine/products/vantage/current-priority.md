# Vantage — Current Priority (conservative mirror)

> This is a **conservative description** maintained by the Learning Spine. It is
> not the source of truth for the running product, and editing it never changes
> the product. Founder-private material must never appear here.

## Audience

GPs, LPs, DFIs, family offices, allocators, and strategic investment teams.

## Aim

Support better capital-deployment decisions using intelligence that is
**source-grounded, permissioned and explainable**.

## Current priority

Vantage is a separate institutional-facing layer. It is **not** being built
through this governance repository. The Learning Spine's only current job for
Vantage is to:

- preserve the boundary that keeps Vantage separate from ScaleSignals;
- record assumptions about whether institutional intelligence can be developed
  later **without weakening founder trust**;
- hold conservative quality expectations (see
  `institutional-quality-tests.yaml`).

## Hard boundary

Vantage must never receive founder-private ScaleSignals material — including
Apius pilot evidence — unless a separate consent, privacy and governance
architecture is explicitly approved (see `charter/product-boundaries.md` and
`charter/data-and-consent-policy.md`).

## What is explicitly out of scope right now

- Building Vantage features through this repository.
- Deriving Vantage intelligence from founder-private inputs.
- Any merge of ScaleSignals and Vantage.
